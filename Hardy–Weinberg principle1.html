ハーディ・ワインベルグの法則

遺伝子頻度 p を動かしながら、遺伝子型頻度 p² : 2pq : q² がどう決まるかを確かめよう。

遺伝子頻度 p と遺伝子型頻度の関係

実線●=AA(p²)、破線▲=Aa(2pq)、点線■=aa(q²)。縦の破線が現在の p です。

グラフから読みとること

AA = p² Aa = 2pq aa = q² (q = 1 − p)
  • Aa(ヘテロ)は p = q = 0.5 のとき最大で、その値は 2 × 0.5 × 0.5 = 0.5。ヘテロは 50 % を超えない。
  • p が小さいとき、AA は p² なのでごくまれになる。たとえば p = 0.01 なら AA は 0.0001(1万人に1人)。
  • まれな潜性形質では、aa より Aa のほうがずっと多い。q = 0.01 のとき aa = 0.0001、Aa = 0.0198 で約200倍。
  • AA の曲線と aa の曲線は p = 0.5 を境に左右対称になる。

計算演習(潜性形質の割合から遺伝子頻度を求める)

ハーディ・ワインベルグの法則が成り立つとみなして考えます。小数(例 0.25)または % 記号なしの数値で答えてください。

解き方の型

  1. 潜性形質(aa)の割合が q² にあたる。
  2. q = √(q²) を計算する。
  3. p = 1 − q を求める。
  4. ヘテロ Aa の割合は 2pq。
q² → q = √(q²) → p = 1 − q → Aa = 2pq

注意:ヒトの集団などで実際にこの計算を使うときは、任意交配・移出入なし・自然選択が働かない、といった条件をおおよそ満たす場合に限られます。条件が成り立たない集団では、計算値は目安にすぎません。

法則が成り立つ5つの条件

  • 1. 個体数が十分に大きい小さい集団では偶然による遺伝子頻度の変化(遺伝的浮動)が無視できない。
  • 2. 突然変異が起こらない突然変異が起きると新しい対立遺伝子が生じ、頻度が変わる。
  • 3. 自然選択が働かないどの遺伝子型も生存率・繁殖力が等しい。差があれば有利な遺伝子が増える。
  • 4. 個体の移入・移出がない他集団との間で遺伝子の流入(遺伝子流動)があると頻度が変わる。
  • 5. 自由な交配(任意交配)が行われる特定の遺伝子型どうしが選んで交配すると、遺伝子型頻度がずれる。

これらを満たす集団では遺伝子頻度が世代を通じて変化しません。つまり「進化が起こらない状態」を表す基準であり、実際の集団はふつうどれかの条件を満たさないため、進化が起こると考えられます。

条件1を確かめる:遺伝的浮動のシミュレーション

考えてみよう

  • N を小さくすると、5本の線はどうなりますか。p = 0 や p = 1 に達した集団では、その後どうなりますか。
  • p = 1 になることを対立遺伝子の固定、p = 0 になることを消失といいます。固定・消失が起こると、その集団では遺伝子頻度はもう変化しません。
  • N を大きくすると線のばらつきは小さくなります。これが「個体数が十分に大きい」という条件の意味です。

このシミュレーションは、毎世代 2N 個の配偶子を無作為に選び直すという簡単なモデルです。実際の集団では自然選択なども同時に働くため、変化のようすはより複雑になります。

⚠ 実習・観察を行うときの安全上の注意
  • ビーズ・豆・おはじきなどを使う模擬実験:小さい部品は口や鼻に入れない(誤飲・窒息の危険)。使用後は必ず手を洗う。
  • 豆類・ナッツ類を教材に使う場合は、食物アレルギーのある生徒がいないか事前に確認する。教材の豆は食べない。
  • 床に落ちたビーズは滑って転倒の原因になる。落としたらすぐ拾い、実習後に人数分そろっているか数える。
  • 生物材料(ショウジョウバエ、植物、ヒトの形質調査など)を扱う場合は、生き物や個人情報の扱いに配慮し、教員の指示に従う。ヒトの形質を調べる調査では、答えたくない生徒に無理をさせない。
  • 薬品・火気・電気器具はこの教材では使用しません。使用する実験と組み合わせる場合は、その実験の注意事項に従ってください。
